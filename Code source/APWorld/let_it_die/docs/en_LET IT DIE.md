# LET IT DIE

This Archipelago world targets LET IT DIE Offline Edition.

Current generation scope is the frozen 4HMA Tower of Barbs layout from 1F through 40F.
Randomized checks include room visits, Haters, minibosses, Mushroom Club mushroom purchases,
four selected Gyaku-Funsha shops, eligible blueprint discoveries, and generated Screamer checks.

The external LET IT DIE client is still under development.
